# Security policy

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or discussions.

Report them privately, either:

- via **Security → Report a vulnerability** in this repository, or
- by email to **git@54p.eu**.

Please include the affected version, the SAP release, and steps to reproduce. We confirm receipt within five working days and keep you informed until the issue is fixed.

## Supported versions

Security fixes are provided for the latest release only.
